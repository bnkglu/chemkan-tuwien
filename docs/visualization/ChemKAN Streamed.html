Layer anatomy, live arithmetic

How to count the parameters every φ holds N basis weights · every layer holds nin×nout of them

The whole count rests on one sentence in the paper: a layer connecting nl inputs to nl+1 outputs has nl · nl+1 activation functions, and all the network's parameters live inside those activations. So counting is three steps:

1. activations per layer = nl × nl+1
2. params per activation = N  (the grid size, Eq. 11)
3. add θthermo = m scalars, if the energy equation is on
params = Σlayers (nl × nl+1 × N) + m·[thermo]

nμ does not enter the count. It only decides whether an activation's output is multiplied or added downstream, so it adds no weights. Methane shows why the count grows with the mechanism: the core stays 3 hidden nodes wide, but every layer touching the state scales with m = 52.

coverage The rest of the paper
  • §ITwo long-standing blockers: detailed mechanisms are large, and stiffness makes integration expensive. Prior art: CRNN and SINDy for discovery; ChemNODE and DeepONets for acceleration.
  • §II.AZero-D homogeneous reactor. Eq. 1: dYᵢ/dt = Wᵢω̇ᵢ/ρ, Arrhenius-driven. Eq. 2: dT/dt = −ΣhᵢẎᵢ/c_p. Operator splitting is what lets a 0-D surrogate serve 3-D turbulent flow.
  • §II.BBaselines. DeepONet: branch(u₀) ⊙ trunk(t) → u, no integrator. ChemNODE: m+1 separate MLPs, each learning one gradient, trained in m+1 frozen stages with zero information sharing.
  • §II.CChemKAN: AddKAN (Eq. 7) and LeanKAN (Eqs. 8–10) layers, RBF activations (Eqs. 11–12), kinetic core (Eq. 13) + thermo superstructure (Eqs. 14–15), loss (Eq. 18), two-stage training, forward sensitivity, Tsit5, Adam @ 2×10⁻³.
  • §III.ACase 1, biodiesel transesterification (TG→DG→MG→GL, 3 reactions), isothermal, 30 sampled points, 10⁴ epochs. Kinetics-only core, 4 hidden nodes, nμ=2, 3-pt grids, 156 params vs a 308-param DeepONet.
  • §III.BCase 2, hydrogen-air: all 9 species incl. the H radical ChemNODE dropped; 441 conditions probed (406 unseen); ignition delay accurate across the igniting cases; 2.0× faster in Arrhenius.jl. Weak spot: below ~1000 K.
  • §III.CLimits: 2× is called a conservative floor; step count is unchanged, so the win comes purely from cheaper gradient evaluation.
repository Where the numbers on this page come from

Data. Cantera trajectories from chemkan/data/generated/hydrogen.npz and methane.npz (100 saved points each); biodiesel from chemkan/data/generated/biodiesel_v2.npz (30 saved points; the dataset recorded in the run's config.json, sha256 c79afbfb…). Inputs are always real saved states, so mass fractions and temperatures are physical.

Weights. H₂: S1_seed0/archive/…epoch100000.pt (Stage 1) and S2_seed0_200k/stage2_final.pt (Stage 2). CH₄: S1_seed0/archive/…epoch50000.pt and S2_seed0/archive/…epoch180000.pt. Biodiesel: my run results/biodiesel/chemkan_figure_runs/fig05/chemkan_noise00_seed0/checkpoint_final.pt (156 parameters, noise-free, 10,000 epochs, seed 0), plus the 15 % noise run of the same figure; architecture, RBF, normalization and the divisor 50 are taken from each run's config.json. Its initial weights were not saved; they were recreated with the training script's own code path (torch.Generator().manual_seed(0), glorot_uniform_, in PyTorch 2.13.0) and reproduce the logged epoch-1 losses to within 5.6e-17 (train 0.2845427257475913, validation 0.2587230490994715, history.csv). The H₂ and CH₄ initial weights were not saved, so the page shows the Stage-1 checkpoints that initialized Stage 2 instead (H₂ epoch 100,000; CH₄ epoch 50,000).

Model conventions follow the repository and the authors' released code rather than the paper's text: activations are an RBF sum only (no swish base), φ(x) = Σ wk exp(−((x − ck)/h)²) with c on [−1, 1] and h = 2/(N−1); the first layer reads min-max normalized states without tanh; the LeanKAN layer's inputs pass through tanh; KAN_cor has no tanh; the right-hand side is divided by t_ref (0.6 ms H₂, 5 ms CH₄, 50 for biodiesel).

Predictions were produced by integrating those weights in normalized coordinates with an explicit Dormand–Prince 5(4) solver at the training tolerances (rtol 1e-6, atol 1e-8), in float64. They reproduce the repository's reported errors to four digits: CH₄ training mean 1.2198e-3 and held-out 1.1626e-3; H₂ training median 4.748e-4 and held-out 3.507e-4. Biodiesel trajectories were integrated at rtol 1e-10 and reproduce the noise-free run's logged tight-solver errors (train 7.1047e-5, test 3.1651e-4). The anatomy panel evaluates the same weights live in your browser; at 20 real biodiesel states it agrees with the PyTorch model to within 4.4e-16 for the initial weights and 7.1e-15 for the trained weights (layer sums, edge values, outputs and right-hand side).

Structural claims validated against the ChemKAN paper; LeanKAN routing cross-checked against the LeanKAN paper. Derived quantities are labeled. Motion respects prefers-reduced-motion; nodes are keyboard-focusable.
